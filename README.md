# Платформа интерактивных обучающих презентаций

## Права на контент
Все учебные материалы, тексты, изображения и видео, находящиеся в папках `content/` и `data/`, являются объектами авторского права © [Сафронов Денис].
Любое копирование, тиражирование, распространение, изменение или использование в коммерческих целях строго запрещено.

Конструктор курсов — платформа-шаблон для создания интерактивных презентаций с тестами, видео и появляющимся текстом.

## 🚀 Быстрый старт

1. Откройте `index.html` в браузере (двойной клик)
2. Для создания своего курса:
   - Измените `config/config.js` (название, автор)
   - Измените `content/content.js` (слайды, тексты, вопросы)
   - При желании измените `config/theme.css` (цвета, шрифты)
   - Положите свои картинки/видео в папку `data/`

```
│   ├─ theme.css           ← ЦВЕТА и ОФОРМЛЕНИЕ ★
│   └─ config.js           ← НАЗВАНИЕ и АВТОР ★
├─ content/

└─ data/                   ← МЕДИАФАЙЛЫ ★
```

★ = файлы, которые меняет автор материала

## 🎯 Типы слайдов

| Тип | Описание |
|-----|----------|
| `image` | Просто изображение 16:9 |
| `text-overlay` | Изображение + появляющиеся текстовые плашки |
| `video` | Видео с кастомным плеером |
| `quiz` | Тест с 4 вариантами ответа |

## 🌐 Публикация на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите файлы проекта
3. В Settings → Pages выберите ветку `main` и корень `/`
4. Через 1-2 минуты курс доступен по ссылке

Подробная инструкция — в файле `КАК-ОБНОВИТЬ-КОНТЕНТ.md`.

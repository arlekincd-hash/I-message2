# КАК ОБНОВИТЬ КОНТЕНТ — инструкция для автора материала

Эта инструкция поможет вам создать новый обучающий курс **без навыков программирования**. Вы будете работать только с двумя файлами: `config/config.js` (настройки) и `content/content.js` (слайды).

---

## 📁 Структура проекта

```
/
├─ index.html              ← точка входа (НЕ ТРОГАТЬ)
├─ css/                    ← стили движка (НЕ ТРОГАТЬ)
├─ js/                     ← код движка (НЕ ТРОГАТЬ)
├─ config/
│   ├─ theme.css           ← ЦВЕТА и ОФОРМЛЕНИЕ (можно менять)
│   └─ config.js           ← НАЗВАНИЕ КУРСА, АВТОР (можно менять)
├─ content/
│   └─ content.js          ← СЛАЙДЫ, ТЕКСТЫ, ТЕСТЫ (можно менять)
└─ data/                   ← КАРТИНКИ и ВИДЕО (ваши файлы)
    ├─ slide_00.jpg
    ├─ slide_01.jpg
    └─ video2.webm
```

---

## 🎨 Шаг 1. Настройка оформления (по желанию)

Откройте файл `config/theme.css`. Здесь можно поменять:

- **Цвета** — замените значения после `#` на другие (например, `#2F6BFF` на `#FF5733`)
- **Шрифты** — поменяйте названия шрифтов в кавычках
- **Размеры** — числа с `px` (например, `16px` на `20px`)

**Пример:**
```css
--color-accent: #2F6BFF;  /* Синий акцент */
--color-bg: #F7F8FA;      /* Фон страницы */
```

---

## 📝 Шаг 2. Настройка курса

Откройте файл `config/config.js`. Замените текст в кавычках на свой:

```javascript
const CONFIG = {
    courseTitle: 'Название вашего курса',
    author: 'Ваше ФИО',
    creatorContacts: 'https://telegram.me/ваш_ник',
    creatorContactsLabel: 'Разработчик: Ваше ФИО',
};
```

---

## 🖼️ Шаг 3. Подготовка медиафайлов

1. Положите ваши картинки и видео в папку `data/`
2. Назовите файлы **латиницей**, без пробелов: `slide_00.jpg`, `video_intro.webm`
3. Запомните имена файлов — они понадобятся в контенте

---

## 📄 Шаг 4. Создание слайдов

Откройте файл `content/content.js`. Внутри вы увидите массив слайдов:

```javascript
const CONTENT = {
    slides: [
        // здесь будут ваши слайды
    ]
};
```

### Тип А: Просто изображение

Копируйте этот блок и вставьте в массив `slides`:

```javascript
{
    id: 'slide_00',
    type: 'image',
    media: 'data/slide_00.jpg'
},
```

**Что менять:**
- `id` — уникальное имя слайда (например, `slide_00`, `slide_01`)
- `media` — путь к вашей картинке

---

### Тип Б: Изображение + появляющийся текст

Копируйте этот блок и вставьте в массив `slides`:

```javascript
{
    id: 'slide_01',
    type: 'text-overlay',
    media: 'data/slide_01.jpg',
    blocks: [
        { text: 'Текст первой плашки', order: 1 },
        { text: 'Текст второй плашки', order: 2 },
        { text: 'Текст третьей плашки', order: 3 }
    ]
},
```

**Что менять:**
- `id` — уникальное имя слайда
- `media` — путь к фоновой картинке
- `text` — текст каждой плашки (между кавычками)
- `order` — порядок появления (1, 2, 3...)

**Как работает:** При прокрутке колёсика мыши или нажатии стрелки ↓ плашки будут появляться по одной.

---

### Тип В: Видео

Копируйте этот блок и вставьте в массив `slides`:

```javascript
{
    id: 'slide_02',
    type: 'video',
    media: 'data/video2.webm',
    poster: 'data/slide_00.jpg'
},
```

**Что менять:**
- `id` — уникальное имя слайда
- `media` — путь к вашему видео
- `poster` — путь к картинке-заставке (по желанию)

**Как работает:** На слайде будет заставка с кнопкой Play. Клик — видео стартует со звуком.

---

### Тип Г: Тест (Quiz)

Копируйте этот блок и вставьте в массив `slides`:

```javascript
{
    id: 'slide_03',
    type: 'quiz',
    question: 'Ваш вопрос?',
    correctAnswerIndex: 0,
    options: [
        { 
            text: 'Вариант ответа 1', 
            isCorrect: true,
            feedback: 'Почему это верно'
        },
        { 
            text: 'Вариант ответа 2', 
            isCorrect: false,
            feedback: 'Почему это неверно'
        },
        { 
            text: 'Вариант ответа 3', 
            isCorrect: false,
            feedback: 'Почему это неверно'
        },
        { 
            text: 'Вариант ответа 4', 
            isCorrect: false,
            feedback: 'Почему это неверно'
        }
    ]
},
```

**Что менять:**
- `id` — уникальное имя слайда
- `question` — текст вопроса
- `correctAnswerIndex` — номер правильного ответа (считается с 0: первый=0, второй=1, третий=2...)
- `text` — текст каждого варианта
- `isCorrect` — `true` для правильного ответа, `false` для неправильных
- `feedback` — пояснение, которое появится после выбора

**Как работает:** Пользователь выбирает вариант. Если неверно — появляется пояснение, кнопка «Далее» заблокирована. Если верно — кнопка «Далее» разблокируется.

## 🏁 Шаг 5. Финальный экран

Финальный экран добавляется **автоматически** после последнего слайда. На нём показывается результат тестов: «Вы ответили верно на X из Y вопросов».

**Не нужно добавлять финальный слайд вручную!**

## 🚀 Как выложить на GitHub Pages

1. **Создайте репозиторий на GitHub** (например, `my-course`)
2. **Загрузите файлы** через веб-интерфейс или Git:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/my-course.git
   git push -u origin main
   ```
3. **Включите GitHub Pages**:
   - Зайдите в Settings → Pages
   - Выберите ветку `main` и корень `/`
   - Нажмите Save
4. **Готово!** Через 1-2 минуты ваш курс будет доступен по ссылке вида:
   `https://ВАШ_НИК.github.io/my-course/`

## ❓ Частые вопросы

**В: Можно ли добавить больше 4 вариантов в тесте?**  
О: Нет, в этой версии теста поддерживают ровно 4 варианта.

**В: Как сделать, чтобы плашки были справа, а не слева?**  
О: В текущей версии плашки позиционируются автоматически. Для изменения позиции нужно править `js/reveal.js` (это уже работа программиста).

**В: Можно ли использовать свои шрифты?**  
О: Да, замените ссылки на Google Fonts в `index.html` и поменяйте названия в `config/theme.css`.

**В: Почему картинки не загружаются на GitHub Pages?**  
О: Проверьте:
- Имена файлов написаны латиницей
- Регистр букв совпадает точно (`Slide_00.jpg` ≠ `slide_00.jpg`)
- Пути в контенте начинаются с `data/` (например, `data/slide_00.jpg`)
